# 🏨 Smart Hotel Management System

A modern **Hotel Management System** developed using **Python Flask, SQLite, HTML, CSS, JavaScript, and Bootstrap**.

The project allows users to search hotels, book rooms, make demo payments, write reviews, manage wishlists, and interact with an AI-powered chatbot. It also provides an advanced admin dashboard for managing hotels, bookings, reviews, and analytics.
